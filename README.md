# Экспериментальные скрипты к курсовой работе

## Структура папки

```
проект/
├── main_fixed.py             ← обновлённый main.py с PPX-кроссовером и счётчиком NCE
└── experiments/
    ├── exp1_density.py        — Серия 1: влияние плотности графа        → Таблица 2.3
    ├── exp2_scalability.py    — Серия 2: масштабируемость               → Таблица 2.4
    ├── exp3_convergence.py    — Серия 3: анализ сходимости + график     → §2.6.3
    ├── exp4_initialization.py — Серия 4: стратегии инициализации        → Таблица 2.5
    ├── exp5_structure.py      — Серия 5: разные классы графов           → Таблица 2.6
    ├── exp6_stability.py      — Серия 6: устойчивость + 95% ДИ + Манн-Уитни → Таблица 2.7
    ├── exp7_nce.py            — Серия 7: число вычислений целевой функции → Таблица 2.8
    ├── param_tune_ga.py       — подбор N и G для ЭГА                    → Таблица 2.1
    └── param_tune_sa.py       — подбор α для ИО                          → Таблица 2.2
```

## Установка

```bash
pip install networkx matplotlib
```

Для серии 6 (Манн-Уитни и ДИ) ничего дополнительного не нужно — расчёт идёт на чистом Python.

## Как использовать

1. Скопируй `main_fixed.py` в корень проекта (или замени им свой `main.py`).
2. Положи папку `experiments/` рядом — внутри лежат все скрипты.
3. Запускай по очереди:

```bash
cd experiments
python exp1_density.py
python exp2_scalability.py
python exp3_convergence.py
...
```

Каждый скрипт:
- выводит ход прогона построчно (видно, что считается);
- в конце печатает сводную таблицу **в формате, готовом к переносу в отчёт**;
- для серии 3 дополнительно сохраняет `convergence.png` рядом со скриптом.

## Настройка параметров эксперимента

В начале каждого файла лежит блок `# ----- параметры -----`. Если хочешь увеличить точность — увеличь `RUNS_PER_GRAPH` или `GRAPHS_PER_P`. Если надо быстрее — уменьши.

Дефолтные значения подобраны так, чтобы эксперимент завершался за разумное время:

| Скрипт | Примерное время |
|--------|-----------------|
| param_tune_sa.py | ~10 сек |
| exp1_density.py | ~4-5 мин |
| exp4_initialization.py | ~5 мин |
| exp6_stability.py | ~2 мин |
| exp7_nce.py | ~30 сек |
| exp3_convergence.py | ~15 сек |
| exp2_scalability.py | ~10 мин (n=200 долго) |
| exp5_structure.py | ~15 мин |
| param_tune_ga.py | ~10-15 мин |

## Что важно понимать

1. **Сидирование.** Все эксперименты используют `SEED = 42` для воспроизводимости. Если хочешь несколько независимых наборов — поменяй seed и запусти заново.

2. **Импорт алгоритмов.** В каждом скрипте стоит `try: from main_fixed ... except: from main ...` — то есть если ты переименуешь `main_fixed.py` в `main.py`, скрипты автоматически подхватят его.

3. **NCE (число вычислений целевой функции).** Подсчёт ведётся через атрибут `solver.fitness_evaluations`. Этот атрибут есть только в `main_fixed.py`; в исходном `main.py` его нет.

4. **Ранний останов ЭГА.** В `main_fixed.py` появился параметр `stagnation_limit=80`: если 80 поколений подряд лучшая особь не улучшается — алгоритм заканчивает работу. Если хочешь полный прогон 500 поколений (как раньше) — передай `stagnation_limit=500` при создании.

5. **Графики.** Только `exp3_convergence.py` строит график. Если у тебя нет установленного `tkinter`/GUI — добавь в начало строку `matplotlib.use('Agg')`.
